# ALPHA V2 — Autonomous Learning Core

Alpha V2 is a local-first autonomous software agent prototype designed for:
- persistent memory
- learning from observations and experiments
- self-modeling and introspection
- controlled strategy evolution
- optional Internet research
- human ↔ Alpha communication
- complete evolution/event journaling
- a dark mobile-friendly web interface

## Important architecture principle

Alpha is an experimental software agent, not a claim of consciousness.
Every generated response is tagged with its source:
- `alpha` = generated by the Alpha engine
- `tool` = returned by an external tool
- `fallback` = static/local fallback
- `human` = supplied by the user

Interpretations are kept separate from Alpha's raw output.

## Run

```bash
python start.py
```

Then open the displayed local URL.

Optional Internet research:

```bash
python start.py --internet
```

The Internet tool is deliberately constrained:
- explicit HTTP/HTTPS URLs only
- request timeout
- maximum response size
- no shell execution
- no arbitrary code execution
- fetched pages are treated as untrusted information

## Storage

Alpha stores persistent state in `alpha_core/storage/alpha_state.json`.

The state contains:
- short-term context
- long-term memories
- learned concepts
- experiments
- strategies
- self-model observations
- evolution journal

A snapshot is created before evolution changes.

## Evolution

Alpha can propose and apply bounded changes to internal strategies and parameters.
It does NOT rewrite or execute arbitrary source code by itself.

This keeps evolution measurable and reversible.

## Web application

The `web/` directory is a static front-end. It communicates with the Alpha HTTP server when the server is running.

GitHub Pages can host the front-end, but a persistent Alpha process requires a server/container/VM with persistent storage.
